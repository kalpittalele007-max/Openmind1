# OpenMind AndroidIDE

Android WebView shell for the OpenMind platform, prepared for AndroidIDE.

## Open in AndroidIDE

Clone this repository, then open the repository root. It should contain `settings.gradle` and `app/`.

## Local OpenMind server

The app is configured for development against:

`http://127.0.0.1:3000`

Run the OpenMind Node/pnpm server separately (for example in Termux), then build/install this Android project.

## Build

Use AndroidIDE's Gradle build / Assemble Debug APK.
